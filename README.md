# Міні-CRM «Зелена Полиця»

Навчальний тренажер CRM інтернет-магазину до курсу «Бізнес-інформатика» (ДУІКТ, спеціальність 073 «Менеджмент»).

**▶ Відкрити тренажер: https://artem-zavgorodniy.github.io/crm-sandbox/**

Сюжет: «Зелена Полиця» продає в роздріб — косметику, горіхи, каву, товари для дому. Покупці пишуть в Instagram Direct, оформлюють замовлення на сайті чи телефонують у Viber. У CRM уже є 30 звернень з історією; студент обробляє чотири нові й аналізує воронку.

## Що показує тренажер

| Частина | Ідея |
|---|---|
| Воронка | етапи Звернення → Консультація → Замовлення → Отримано, окремо «Скасовано» з причиною |
| Картка клієнта | уся історія покупця в одному місці: канал, товар, оплата, новий чи постійний |
| Правило переходу | звернення не можна перемістити далі, поки не записана потрібна дія — тому воронка показує правду |
| Звіт | конверсія між етапами, канали, нові й постійні клієнти, спосіб оплати, причини скасувань, звернення без відповіді понад 2 дні |

## Дані

Імена покупців і товари взяті з навчальної бази «Зеленої Полиці» — вигаданого інтернет-магазину; реальних людей вони не стосуються.

## Технічно

Одна сторінка без зовнішніх бібліотек. Прогрес зберігається в браузері (localStorage) і нікуди не надсилається; «Почати спочатку» повертає початковий стан.
